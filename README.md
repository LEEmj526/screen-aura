# Screen Aura

A little light. A little more calm.

Screen Aura is a native macOS menu-bar app that adds gentle edge lighting and focus-timer signals to your display.

**Current status: 0.3.0 development preview.** The free MVP is implemented. The Pro edition is not released. Gumroad sales are on hold until the paid Pro release is ready.

## Development download

[GitHub development releases](https://github.com/LEEmj526/screen-aura/releases)

Requires macOS 13 or later. Universal executable includes Apple Silicon and Intel architectures. The downloadable build is ad-hoc signed, **not Developer ID signed or notarized**. macOS may prevent opening it; it is intended for development evaluation. Clean-machine and physical multi-display validation remain pending.

## Included in the free MVP

- Calm Mist and Afterglow presets, custom colors, width, intensity, softness and per-edge controls
- Transparent click-through per-display overlays with breathing, sweep and corner signals
- Focus timer with pause/resume, restart restoration and completion signals
- Display preferences, day/night scheduling, app exclusions and local JSON import/export
- Korean and English settings; optional login launch, off by default
- Reduced-motion and low-power behavior

Pro presets, licensing/trials, battery signals, automatic app profiles and automatic updates are not available in this preview.

## Privacy

No account, analytics, screen capture, Accessibility permission or remote processing is used. Settings stay on your Mac. See [privacy notes](PRIVACY.md).

## Installation and use

Open the DMG, drag ScreenAura to Applications and launch the app if your Mac permits this development build. Use the menu-bar sparkle to open settings, choose a preset, adjust the halo, or start a focus timer. Quit from the same menu. Login launch is optional.

See [validation results](TEST_RESULTS.md) and [release notes](RELEASE_NOTES.md). Report reproducible issues through this repository's Issues tab. Source is maintained in a separate private repository; this repository contains public documentation and development downloads.
